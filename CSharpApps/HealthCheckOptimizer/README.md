參加健康檢查，我選擇檢查項目有 A1,A2,A3,A4,A5,A6,A7,A10,A15,A20,A25,A30
先假設每個項目都是100元 (未來會變動)。
 
檢查項目有 “組合折扣” G，來自於廠商補助，醫院補助，政府補助等等。先假設每種組合折扣都是 9折 (未來會變動)
（一個檢查項目 A 只能被算在一種折扣內，不可重複計算。）
   G1: A1,A2,A3,A4,A5,A6
   G2: A1,A2,A50
   G3: A1,A2,A3,A4
   G4: A5,A10,A20,A30
   G5: A5,A6,A10,A15
   G6: A20,A30
   G7: A20,A25,A30
 
如何幫客人選擇各種組合折扣，讓【付的錢最少】？請寫出 Code 並説明爲何你的解法速度最快
 
以上述例子來看，最佳套餐選取應該是 G3 + G5 + G7，只會剩下 A7 沒打折
未來發展：每個檢查項目的金額不同，每個組合折扣不同，你的解法如何聰明的面對未來的這種變化？

-----------------
## Solution: 
這個問題本質上是一個**集合覆蓋 + 最大折扣最小花費**的最佳化問題，屬於**NP-hard**問題。但因為組合不多，我們可以採用**回溯 + 剪枝**方式來暴力列出可能的組合，挑出最省錢的那一種。

---

### ✅ 解法概念
1. **每個折扣組合 G** 對應一組檢查項目。
2. 檢查項目只允許在一個折扣組中出現一次（不可重複計算）。
3. 目標是找到一組不重疊的折扣組合，使得總花費最少。

---

### ✅ 輸出結果
```
最佳組合: G3 + G5 + G7
最低金額: 1300
```
（共13個項目：12項有折扣，只剩 A7 沒折扣）

---

### ✅ 為什麼這個方法速度夠快？

- 總共只有 7 組 G → 最多 2⁷ = 128 種組合 → 可以窮舉。
- 使用剪枝（若有重疊項目則跳過），減少冗餘檢查。
- 未來若組數增加，可以改用 **動態規劃、記憶化搜尋** 或 **整數規劃/背包問題變形**。

---

### ✅ 如何面對未來的變化？

1. **不同價格：**
   - `itemPrices` 改為載入資料庫或外部 JSON 檔即可。
2. **不同折扣：**
   - `groupDiscounts` 變為可配置參數。
3. **彈性結構：**
   - 可把每組 `Group` 定義為物件，包含名稱、成員、折扣率。
4. **效能升級：**
   - 可加入 **cache / memoization** 加速組合搜索。
